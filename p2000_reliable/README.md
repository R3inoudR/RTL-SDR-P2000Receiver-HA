# P2000 RTL-SDR Reliable

Receive P2000 FLEX messages using an RTL-SDR dongle and publish filtered sensors to Home Assistant via MQTT.

See [DOCS.md](DOCS.md) for installation, configuration, migration and reliability limits.

This implementation is derived from [cyberjunky/addon-p2000_rtlsdr](https://github.com/cyberjunky/addon-p2000_rtlsdr), version 1.0.9, commit `d9245923d2f530dd94216f2873b51bb418717d62`. The upstream license is preserved in [LICENSE](LICENSE). It is separate from the older standalone receiver in the repository root.
